À propos de la pondération

Le score global de similarité est une moyenne pondérée des 6 critères :

    {% for c in criteria %}
  • {{ icons.icon(crit_icons[c], 13) }} {{ labels[c] }}
    • {% endfor %}

Un critère à 0 % est ignoré dans le calcul. Augmenter le poids d'un critère (ex. Images, pour mieux détecter le plagiat visuel) réduit mécaniquement l'influence des autres.

Ce réglage s'applique immédiatement à toutes les comparaisons et scans à venir — il ne modifie pas les scores déjà affichés ailleurs.
